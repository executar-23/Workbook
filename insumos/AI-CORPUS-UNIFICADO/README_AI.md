# AI_CORPUS_UNIFICADO

Corpus consolidado a partir de `Arquivo(1).zip`.

## Convenção de IDs

- Regex: `^AIKB-[0-9]{4}$`
- Nome de arquivo: `<ID>__<slug-ascii>.<ext>`
- Os formatos originais foram preservados.
- Subpastas e metadados `__MACOSX/._*` foram removidos.
- `MANIFEST_AI.jsonl` é o índice canônico para ingestão por agentes.
